# Wine-Quality-Prediction-Web-App

Developed a Wine Quality Prediction Web Application that uses a machine learning model to predict wine quality based on various chemical attributes. The project involved data preprocessing, feature selection, and training a model using Python and scikit-learn. A FastAPI-based web application was built to allow users to input wine parameters and receive real-time predictions through an interactive HTML/CSS interface. The trained model was serialized using Joblib and the application was containerized with Docker to ensure scalable and efficient deployment.
